# MAKA

동료들이 함께 맛집을 추천하고 댓글을 남기는 사내 맛집 공유 사이트입니다.

- 조회는 누구나 가능, 등록·댓글은 구글 로그인 필요
- 카테고리 / 추천 시간대 / 함께하기 좋은 사람 필터
- 맛집 등록 +10점, 댓글 +3점, 내 글에 댓글 받으면 +1점 → 레벨업(Lv1 새싹 ~ Lv5 맛집전설)
- 리더보드, 마이페이지, 관리자 삭제 권한

설치·배포 방법은 `SETUP_GUIDE.md`를 참고하세요. DB 스키마는 `supabase/schema.sql`, 샘플 데이터는 `supabase/seed.sql`에 있습니다.
